# Relay

Relay 是一个基于 LSPosed API 102 的 Android 模块，用于把**小米**设备上的应用通知和短信验证码转发到远程 TCP 服务器。

项目名称来源于[信驿 Relay](https://gitlab.com/magisk3171/xinyi-relay)。

模块仅在 小米17 上经过测试，不保证其它米系设备的可用性。

## 工作方式

对于应用通知，模块通过 Hook 系统进程捕获通知内容。

对于短信验证码，由于小米的短信 App 自带验证码提取功能，模块通过 Hook 短信 App 捕获验证码。由于短信 App 被混淆，模块通过 [DexKit](https://github.com/LuckyPray/DexKit) 动态搜索所需类和方法，以尽量提高兼容性。

通知和验证码转发到同一个服务器地址，但分别使用两个不同的端口。每条消息建立一个 TCP 连接，写入一行 UTF-8 JSON 后关闭连接。

由于所有发送消息的逻辑均在宿主内部实现，模块不需要常驻后台运行。

## 安装与使用

1. 由于实现了热重载，模块仅支持 LSPosed API 102。
2. 对于短信验证码转发，由于从短信中提取验证码的能力来自小米短信应用本身，该功能仅支持小米设备。
3. 对于通知转发，理论上支持所有安卓设备。在模块界面中可以选择要转发的目标应用。

已测试通过的设备：小米17 系统版本 3.0.315/3.0.318；短信 App 版本 17.0.3.7

## TCP 协议

服务器应按“每个连接读取一行 JSON”的方式处理数据。消息末尾始终有换行符 `\n`。

通知使用以下格式：

| 字段        | 含义   |
|-----------|------|
| `title`   | 通知标题 |
| `content` | 通知内容 |

例如：
```json
{"title":"登录提醒","content":"你的验证码是 123456"}
```

短信使用以下格式：

| 字段         | 含义          |
|------------|-------------|
| `msg`      | 短信原文        |
| `sms_code` | 从原文中提取出的验证码 |

```json
{"msg":"【示例服务】验证码为 123456，5 分钟内有效。","sms_code":"123456"}
```

字符串使用 UTF-8 JSON 转义。服务器应在连接写入成功后完成本条消息处理，不要依赖长连接或 ACK。

Relay 当前**不会发送令牌，也不提供 TLS 加密**，数据均为**明文传输**。
